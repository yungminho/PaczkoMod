# PaczkoMod
Mod do Minecraft: Java Edition oparty o Fabric, dodający elementy inspirowane Paczkomat® oraz mechaniką przesyłek.

> ❗Zastrzeżenie❗\
> Ten projekt jest **nieoficjalny** i tworzony hobbystycznie. \
> **Nie jestem powiązany z firmą InPost Sp. z o.o.** ani żadnym innym podmiotem z nią związanym. \
> Nazwy, znaki towarowe, logotypy oraz marki należące do **InPost** są własnością ich prawnych właścicieli i zostały użyte wyłącznie w celach informacyjnych lub inspiracyjnych.

## Funkcje
- Globalny, współdzielony ekwipunek paczek
- Mechanika płatności za nadanie paczki
- Integracja z Fabric API
- Zapis danych przy użyciu PersistentState

## Wymagania
- Minecraft Java Edition 1.21.1
- Fabric Loader 0.18.2 lub nowszy
- Fabric API
- Java 17 lub nowsza

## Instalacja
1. Zainstaluj Fabric Loader
2. Pobierz Fabric API
3. Pobierz plik `.jar` moda z zakładki **Releases**
4. Umieść plik w folderze `mods`
5. Uruchom grę

## Budowanie ze źródeł
```
git clone https://github.com/yungminho/paczkomod.git
cd paczkomod
./gradlew build
```

gotowy plik `.jar` znajdziesz w \
`build/libs/`
